Home Assistant Calendar

A private connection between one person's own Google Calendar and their own Home Assistant server at home. It shows the week's events on a wall display in the house.

What it does

  • Reads calendar events so the home display can list today's and this week's agenda.
  • Runs only on a Home Assistant server on a private home network. There is no public service, no other users and nothing to sign up for.

Who can use it

Only the owner of the Google account it was set up for. It is not offered to anyone else.
